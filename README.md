# EcoHogar - Plataforma Digital Centralizada para Propiedad Horizontal

**Proyecto de Grado – Ingeniería de Sistemas (UNAD)**  
**Autores:** Carlos Eduardo Peña Garcés, Virginia Ríos Santiz, María Camila Arias Quintanilla  
**Tutor:** Orlando Gómez Barboza  
**Ubicación:** San Martín, Cesar, Colombia

## Descripción
Plataforma web centralizada diseñada bajo el marco CDIO y metodología ágil Scrum para optimizar la administración operativa y el monitoreo energético/hídrico en conjuntos residenciales y copropiedades bajo la Ley 675 de 2001.

## Módulos Implementados (MVP - TRL 5)
- **Autenticación y Roles (RBAC):** Acceso diferenciado para Administrador, Residente y Comerciante.
- **Gestión de PQRS:** Radicación de solicitudes con código único de ticket y sello de tiempo (`America/Bogota`).
- **Reserva de Espacios Comunes:** Calendario con validación de intersección horaria anti-traslapes.
- **Dashboard Energético e Hídrico:** Registro de lecturas (kWh / m³), cálculo automático de tarifas en COP y gráficos comparativos con Chart.js.
- **Cartelera Informativa y Perfil de Usuario.**
